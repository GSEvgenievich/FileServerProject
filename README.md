**Клиент-серверное приложение для управления и обмена файлами с использованием ASP.NET Core Web API, WPF-клиента и Docker-контейнеризации.**

---

## 🎯 Цель проекта

Этот проект представляет собой полноценную систему для загрузки, хранения и управления файлами. Он демонстрирует навыки разработки распределенных приложений с использованием современных технологий .NET, включая контейнеризацию и многослойную архитектуру.

Проект включает:
- **Серверную часть (API)** для обработки запросов и управления файлами.
- **Клиентское приложение (WPF)** для удобного взаимодействия с системой.
- **Контейнеризацию (Docker)** для простого развертывания и масштабирования.

## 🛠 Технологии и архитектура

**Стек:**
- **Фреймворк:** .NET 8.0 LTS
- **Язык:** C# 12.0
- **Сервер:** ASP.NET Core 8.0 Web API
- **Клиент:** WPF (.NET 8.0)
- **Контейнеризация:** Docker, Docker Compose
- **Документация API:** Swagger / OpenAPI

**Архитектура:**
Проект построен по принципам **чистой архитектуры** и **разделения ответственности** с четким разделением на слои:

1.  **`FileServer.WPF`** — десктопный клиент для загрузки и управления файлами.
2.  **`FileServer.API`** — веб-API для обработки запросов и управления файловой системой.
3.  **`FileServer.Domain`** — слой бизнес-логики и сущностей.
4.  **`FileServer.Infrastructure`** — слой доступа к данным и внешним сервисам.
5.  **`WebApplication1`** — вспомогательное приложение (уточните назначение, если необходимо).

**Для пользователей (WPF-клиент):**

## 🚀 Как запустить локально

### Предварительные требования
- Установленный **.NET 8.0 SDK**
- Установленный **Docker** и **Docker Compose** (для запуска через контейнеры)
- **(Опционально)** Visual Studio 2022 для разработки

### Способ 1: Запуск с использованием Docker (рекомендуемый)

Этот способ гарантирует, что все зависимости и сервисы будут работать в изолированной среде.

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/GSEvgenievich/FileServerProject.git
    cd FileServerProject
    ```

2.  **Запустите проект с помощью Docker Compose:**
    ```bash
    docker-compose up --build
    ```
    После сборки и запуска API будет доступно по адресу `http://localhost:5000`, а Swagger — по адресу `/swagger`.

### Способ 2: Запуск через PowerShell скрипт

Проект включает скрипт для быстрого запуска.

1.  **Клонируйте репозиторий** (как описано выше).
2.  **Запустите скрипт:**
    ```bash
    ./start.ps1
    ```

### Способ 3: Ручной запуск (для разработки)

1.  **Клонируйте репозиторий.**
2.  **Откройте решение** `FileServerProject.sln` в **Visual Studio 2022**.
3.  Установите проект `FileServer.API` в качестве **стартового** и запустите его (F5). API будет доступно локально.
4.  Отдельно запустите проект `FileServer.WPF` для работы с клиентским приложением.

## 📦 Контейнеризация

Проект полностью готов к работе с Docker. Конфигурация описана в файле `docker-compose.yml`. Это позволяет легко развернуть приложение в любой среде, поддерживающей Docker.
